# idea atelier

思いつきを記録し、実現への小さな一歩に分け、選んだ情報だけを誰かと共有するための日本語Webアプリです。

## 使い方

`index.html` をブラウザで開くと使えます。アカウントやサーバーは使わず、アイデア帳は利用中のブラウザの `localStorage` に保存します。端末を移すときは「データを書き出す」でバックアップし、新しい端末で「データを読み込む」を使ってください。

共有したいアイデアの「共有する」から公開項目を選びます。共有リンクには選択した内容のみが含まれます。公開タイトル、表示名、活動エリア、伏せたい語句、連絡先候補の自動マスキングを調整したあと、プレビューを確認してリンクをコピーしてください。リンクのデータはURLのフラグメントに入るため、サーバーには送られません。リンクを知っている人は内容を閲覧でき、受け取った人が転送する可能性があります。

## 検索除け

ページに `noindex` メタタグを設定しています。これは検索エンジンにページを登録しないよう依頼する設定で、検索結果からの除外を保証するものではありません。また、公開GitHubリポジトリのソースコードはGitHub上で検索・閲覧される可能性があります。**GitHub検索にも載せたくない場合は、リポジトリをPrivateにしてください。**

## いまの構成と今後

- 現在は個人の端末内で動くフロントエンド試作です。複数端末同期、ログイン、共有リンクの失効、協力者募集や応募管理はまだありません。
- 将来、実現したい人が参加する仕組みを足す場合は、公開する情報の確認、応募者との連絡、公開停止、削除依頼の流れを設計してからサーバー機能を追加します。
- `style.css` のGoogle Fonts読み込みは、オンライン環境で書体を取得します。文字データはGoogle Fontsへ送信されます。完全なオフライン利用にする場合はこの読み込みを外してください。
